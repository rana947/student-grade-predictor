# 🎓 Student Grade Predictor

A Machine Learning project that predicts student 
grades based on attendance, sessional, midterm 
and final exam marks.

## 🛠️ Technologies Used
- Python 3.12
- scikit-learn (Decision Tree)
- pandas & numpy
- MySQL Database
- VS Code

## 📊 Features
- Predicts grades: A+, A, B, C, D, F
- Based on Pakistan university marking system
- Trained on real student data
